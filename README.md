# tjc-daxi-events
真耶穌教會大溪教會 - 年度季佈道會專區 (TJC Daxi Seasonal Events)

本 Repository 用於集中存放真耶穌教會大溪教會「整年四季（春、夏、秋、冬）」的季佈道會電子邀請卡與海報底稿。 每次舉辦活動時，只需進入對應季節的資料夾修改文字與主題，即可快速發布！

📁 資料夾架構與檔名規範 (Directory Structure)

建議 GitHub Repository 名稱：tjc-daxi-events 或是 tjc-daxi-2026

tjc-daxi-events/
├── README.md                           <-- 專案說明手冊
├── index.html                          <-- 🌟 年度總入口首頁 (導覽至四季)
│
├── spring/                             <-- 🌸 春季佈道會專區
│   ├── index.html                      <-- 春季電子邀請卡底稿 (綠/粉色系)
│   └── og-image.jpg                    <-- 春季 LINE 分享縮圖
│
├── summer/                             <-- ☀️ 夏季佈道會專區
│   ├── index.html                      <-- 夏季電子邀請卡底稿 (藍/黃色系)
│   └── og-image.jpg
│
├── autumn/                             <-- 🍁 秋季佈道會專區
│   ├── index.html                      <-- (可放入先前製作的「生命的道路」)
│   └── og-image.jpg
│
└── winter/                             <-- ❄️ 冬季佈道會專區
    ├── index.html                      <-- (可放入先前製作的「走過死蔭幽谷」)
    └── og-image.jpg

舉辦地點：真耶穌教會大溪教會 (桃園市大溪區民權東路185巷31號)
